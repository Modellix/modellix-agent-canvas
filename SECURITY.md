# Security policy

Please report suspected vulnerabilities privately to [support@modellix.ai](mailto:support@modellix.ai). Do not open a public issue containing API keys, credentials, private prompts, uploaded images, signed result URLs, or local filesystem paths.

Include the affected version, host, operating system, reproduction steps, and impact. Use a new test credential when possible and revoke it after testing. Modellix will acknowledge the report and coordinate disclosure after a fix is available.

Only the latest released version is supported with security fixes. For account or data-privacy requests, see the [Modellix Privacy Policy](https://www.modellix.ai/privacy).
